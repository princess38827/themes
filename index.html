EXPLAIN IT TO A FRIEND

THE AGENT

A dot with a decision rule.

Think of each dot as a tiny software participant. It has a position, a shared eastward goal, and rules for responding to reports from its peers. It does not chat or think like an AI assistant.

THE DIFFERENCE

Not all reports deserve equal weight.

Simple averaging combines received reports directly. ECHO uses a median-based heuristic and sender trust to screen unusual reports. Both face the same seeded starting conditions and message-loss randomness.

THE QUESTION

Can the pattern hold up?

The demo makes one idea visible. Real networks, other attacks, and more trials could change the outcome. Exploring this replay is a starting point for asking better questions.

REAL OUTPUT. SIMULATED WORLD.

A prototype,
with boundaries.

No robots, radios, real EEG, quantum hardware, or biological experiments were used. This is a software-only, two-dimensional experiment—not a field demonstration, a marketplace of AI models, or a safety guarantee.

Trust bookkeeping is idealized and shared centrally. There is no radio range, latency, congestion, or collision avoidance. Initial intent is preloaded, faults are scripted, and three seeds are a small sample. This does not establish which interface works best with people; that needs user testing.

How is coherence calculated?

Coherence = 0.6 × clipped(progress / 25) + 0.4 × clipped(1 − spread / 20). Progress is mean eastward displacement; spread is mean distance from the final centroid. Values are clipped to 0–1. Scales are experiment-specific.

Faulty agents remain in the whole-fleet result. Honest-only scores are a separate diagnostic and cannot replace it. No formal Byzantine proof or performance guarantee is established.

Can I talk to these agents or change the experiment?

No. These are recorded numerical agents, not connected LLMs. To change packet loss, agent counts, attacks, or random seeds, run the Python simulation from the source repository. Replay controls only explore the existing recording.
